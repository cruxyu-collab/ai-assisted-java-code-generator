# Requirements — MVP 0.1

## 범위
- 입력: 가상의 일본어 설계서에서 추출했다고 가정한 JSON
- 현재 구현: 데이터 구조 및 정적 검증
- 후속 구현: AI 추출, Java DTO 생성, 실제 Java 컴파일

## 데이터 계약
- `class_name`: Java 클래스명
- `fields`: 하나 이상의 필드 목록
- 각 필드: `name`, `type`, `required`, `description`
- 허용 자료형: `String`, `int`, `long`, `boolean`
- 추가 속성은 허용하지 않음

## 검증 규칙
1. JSON 구조와 필수 속성이 올바를 것
2. 클래스명/필드명은 Java 식별자 규칙을 만족할 것
3. Java 예약어를 식별자로 사용하지 않을 것
4. 필드명이 중복되지 않을 것
5. 지원하지 않는 자료형을 거부할 것
6. 필드는 최소 1개 이상이어야 할 것
7. 검증 실패 시 성공 결과를 반환하지 않을 것

## 완료 조건
- 정상 데이터 테스트 통과
- 필수 속성 누락 테스트 통과
- 중복 필드 테스트 통과
- 미지원 자료형 테스트 통과
- 잘못된 식별자 및 예약어 테스트 통과
- 빈 필드 목록 테스트 통과
- 실제 테스트 실행 결과를 `TEST_RESULTS.md`에 기록

## 명시적 제외
- AI API 호출 및 과금
- Java 코드 생성 및 컴파일
- UI, 데이터베이스, 서버 배포
